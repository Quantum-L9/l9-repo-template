# L9 Repo Template

Drop these files into any L9 Python repo to consume the universal CI base.

1. Copy `.github/workflows/ci.yml`.
2. Copy `.pre-commit-config.yaml`, `.gitleaks.toml`, `requirements-ci.txt`, and the `pyproject.toml` quality blocks.
3. Adjust workflow inputs: `source-dir`, `test-dir`, `coverage-threshold`.
