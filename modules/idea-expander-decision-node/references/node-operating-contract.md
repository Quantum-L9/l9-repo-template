# Node Operating Contract

## Identity

`idea-expander-decision-node` is a post-expansion, pre-authorization decision system. It converts an attractive narrative into a testable commercial and execution thesis.

## Authority Order

1. explicit current user instruction
2. verified evidence in the idea dossier
3. verified L9 constellation contracts and capabilities
4. validated market and financial evidence
5. bounded expert inference
6. Unknown

## Invariants

- separate facts, assumptions, inferences, and Unknowns
- no single perspective can dominate by rhetoric
- fatal constraints override weighted averages
- dissent is preserved
- conditions are executable proof gates, not vague recommendations
- plan refinement may repair identified gaps but may not conceal them
- final authorization must be traceable to evidence and board reasoning

## Node States

- `RECEIVED`
- `NORMALIZED`
- `SWOT_COMPLETE`
- `PLAN_DRAFTED`
- `RED_TEAMED`
- `PLAN_REFINED`
- `BOARD_REVIEWED`
- `DECIDED`
- `AUTHORIZED` or `STOPPED`

## Routing

- `GO`: issue execution authorization.
- `CONDITIONAL_GO`: issue authorization with mandatory gates.
- `HOLD`: issue evidence and repair plan; no execution authorization.
- `NO_GO`: issue rejection rationale and resurrection conditions, if any.
