# Classification and Routing Protocol

Classify the input on independent axes:

- `source_form`
- `maturity`
- `execution_class`
- `analysis_intent`
- `risk_class`
- `external_fact_dependency`
- `autonomy_class`
- `substrate_class`

This avoids treating code, regulation, autonomy, and substrate leverage as mutually exclusive input modes.

The model may determine classification facts where interpretation is needed. Once classification is fixed, routing obligations are deterministic.

See `policies/routing.yaml`.
