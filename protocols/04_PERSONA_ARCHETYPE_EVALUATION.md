# Persona + Thinking-Archetype Evaluation

Select only lenses capable of changing the decision.

Typical persona roles include customer/buyer, founder/operator, investor, regulator/legal, domain expert, competitor, distribution/growth, systems architect, operator/executor, and skeptic/auditor.

Thinking archetypes include analytical, convergent, creative, critical, experiential, exploratory, facilitative, integrative, pragmatic, reflective, strategic, and systems reasoning.

## Rules

- 2–4 meaningful personas is usually enough.
- Delete a lens that produces no decision effect.
- Preserve an opposition/skeptic lens for material decisions.
- Record the modification produced by each activated lens.
- User-alignment context must not overpower market/regulatory reality.
