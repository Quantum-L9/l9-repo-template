# Research / Coding / Runtime Return Loop

## Outbound routing

- material external facts → research contract
- code → coding contract + runtime validation
- hybrid → research before coding when unresolved facts materially affect architecture
- runtime claim → runtime validation contract

## Return law

Downstream agents must return typed envelopes. Results are integrated into the existing Idea Decision Packet.

Recalculate only affected fields:

```text
return evidence
  ↓
changed assumptions?
  ├─ no → preserve packet
  └─ yes → recalculate impacted wedge / route / risks / promotion
```

Do not restart the whole pipeline unless blast radius requires it.
