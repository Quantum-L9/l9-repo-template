# Governed Learning Loop

IdeaOS may learn from:

- user corrections
- failed routes
- research disproval
- build/runtime outcomes
- repeated friction
- launch outcomes

It may not silently rewrite itself.

```text
Outcome
→ LearningRecord
→ recurrence/evidence check
→ patch candidate
→ benchmark cases added
→ old-vs-new benchmark
→ regression scan
→ promote or reject
```

A change is eligible for promotion only when evidence supports the pattern and benchmark performance improves without critical regression.
