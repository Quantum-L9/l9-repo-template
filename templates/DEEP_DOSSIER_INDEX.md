# Deep Dossier Adaptive Index

Deep mode is obligation-driven, not file-count-driven.

Always include:
1. Executive summary
2. Source inventory when sources exist
3. Source authority / supersession when multi-source
4. Refined center: Dream / Invariant / Wedge / Proof
5. Expansion output when requested or routed
6. Persona/archetype decision effects
7. Substrate assessment when material
8. Evidence / contradictions / Unknowns
9. Routing decision
10. Required modification plan
11. Required downstream contracts
12. Idea Decision Packet
13. Validation / manifest

When expansion is routed, also require:
- `expansion_packet.json`
- candidate disposition coverage
- expansion gate receipt
- decision-node handoff status

Add regulated-service, protected-action, runtime-validation, decision-node, or other artifacts only when triggered.
