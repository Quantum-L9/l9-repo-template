| Boundary | Owner | May do | Must not do |
|---|---|---|---|
| Center formation | model/human | Dream, Invariant, Wedge, Proof | claim runtime proof |
| Idea expansion | `idea-expander` | wide/deep discovery, loops, dispositions, revised center | GO/HOLD/NO_GO |
| Expansion integrity | deterministic gate | structural validation, disposition coverage, handoff readiness | invent semantic content |
| Decision adjudication | `idea-expander-decision-node` | SWOT, plan, red-team, board vote | fabricate evidence |
| Promotion | IdeaOS runtime | enforce readiness gates | weaken failed gates |
| Execution topology | downstream execution system | select authorized executor/topology | rewrite idea meaning |
| Learning | governed learning loop | propose evidence-backed rule changes | silently mutate canon |
