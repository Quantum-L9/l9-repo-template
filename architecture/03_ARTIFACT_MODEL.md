# Artifact Model

Canonical artifacts now include:

1. `IdeaClassification`
2. `RouteDecision`
3. `Center` - Dream / Invariant / Wedge / Proof
4. `ExpandedIdeaDossierPacket` - creative expansion handoff
5. `ExpansionGateReceipt` - deterministic readiness result
6. `DecisionNodeInput` / `DecisionNodeOutput` when adjudication is triggered
7. `IdeaDecisionPacket`
8. downstream research/coding/runtime returns when required
9. `IdeaExecutionPacket`
10. outcome evidence / learning candidates

The expansion packet is not an authorization artifact. The decision output is not an execution topology artifact.
